# Roadmap

## v0.0.x - Technical Base

- Clean Maven structure.
- JavaFX shell.
- PostgreSQL development setup.
- Flyway migration baseline.
- Initial docs and repository hygiene.

## v0.1.0 - Suppliers And Documents

- Supplier model and CRUD.
- Document model and CRUD.
- Basic validation.
- First useful table view.

## v0.2.0 - Attachments

- Local file attachment path model.
- PDF attachment support.
- Basic file open action.

## v0.3.0 - States And Filters

- Manual document states.
- Search and type/date filters.
- Clean table formatting.

## v0.4.0 - CSV Export

- Export document list to CSV.
- Keep export simple and local.

## v0.5.0 - Minimal Dashboard

- Document counts.
- Supplier counts.
- Pending document summary.

## v0.6.0 - Simple Payments

- Optional payment table.
- Paid/unpaid/partial state derived from payments.

## v0.7.0 - UX Pass

- Empty states.
- Error messages.
- Keyboard and table usability improvements.

## v0.8.0 - Tests And Reliability

- Unit tests for state calculation.
- DAO integration tests if PostgreSQL test setup is practical.
- Build instructions verified from a clean clone.

## v0.9.0 - Portfolio Release Candidate

- Demo data.
- Screenshots.
- README polish.
- Changelog cleanup.

- Stable local desktop app.
- Clear project narrative.

## v2.0.0 - Debt And Payments As Product

- Stronger debt panel.

- Better local file organization.
- Document preview and metadata.

## v4.0.0 - Installable Local Product
